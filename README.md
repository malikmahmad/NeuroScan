# NeuroScan

A full-stack web application for brain tumor MRI analysis. Upload an MRI slice and get an immediate classification, a tumor localization overlay, and a visual explanation of what the model looked at — all computed live, no cached results.

> **Research and educational use only.** This is not a certified medical device. Do not use predictions for clinical decision-making.

---

## What it does

- **Classifies** a brain MRI slice into four categories: Glioma, Meningioma, Pituitary tumor, or No tumor
- **Segments** the tumor region using a U-Net, drawing an overlay that shows exactly where the model thinks the tumor is
- **Explains** the prediction visually — Grad-CAM for CNN and EfficientNet, Attention Rollout for ViT
- **Compares** all three architectures on the same image side by side, including an averaged ensemble result
- **Shows training metrics** — accuracy, F1, ROC-AUC, and segmentation Dice/IoU — pulled from the actual training output files

## Models

| Model | Type | Test Accuracy | Macro F1 | ROC-AUC |
|---|---|---|---|---|
| Custom CNN | Trained from scratch | 78.2% | 0.769 | 0.926 |
| EfficientNet-B0 | Transfer learning | 91.6% | 0.913 | 0.985 |
| **ViT-B/16** | **Transfer learning** | **94.7%** | **0.946** | **0.990** |

| Segmentation | Dice | IoU |
|---|---|---|
| U-Net | 0.886 | 0.856 |

All three classification models were trained on the same dataset with identical preprocessing, augmentation, and train/val/test splits. The comparison is fair by design.

---

## Explainability

Grad-CAM is mathematically defined for convolutional feature maps and is **not valid for Vision Transformers** — there is no spatial conv map to extract gradients from. This project uses:

- **Grad-CAM** for CNN and EfficientNet
- **Attention Rollout** (Abnar & Zuidema, 2020) for ViT

Both are computed on the actual uploaded image in real time.

## Getting started

### Requirements

- Python 3.11+
- Node.js 18+

### 1. Train the models

Training requires a GPU. The easiest option is a free Kaggle notebook.

**Classification (CNN, EfficientNet, ViT):**

1. Open [brain-tumor-mri-dataset on Kaggle](https://www.kaggle.com/datasets/masoudnickparvar/brain-tumor-mri-dataset) and click **New Notebook**
2. Go to Settings → Accelerator → **GPU T4 x2** and turn Internet on
3. Click **Add Data**, search for `brain-tumor-mri-dataset`, and add it
4. In the first cell run: `!pip install scikit-learn seaborn -q`
5. In the next cell paste the full contents of `notebooks/train_classification.py` and click **Run All**
6. When done, go to the **Output** tab and download the entire `outputs/` folder
7. Place it at `notebooks/outputs/`

**Segmentation (U-Net):**

1. Open [lgg-mri-segmentation on Kaggle](https://www.kaggle.com/datasets/mateuszbuda/lgg-mri-segmentation) and click **New Notebook**
2. Same GPU settings as above
3. Add the `lgg-mri-segmentation` dataset
4. Paste `notebooks/train_segmentation.py` and run it
5. Download `outputs_segmentation/` from the Output tab
6. Place it at `notebooks/outputs_segmentation/`

### 2. Place the weights

Copy the trained `.pth` files into `backend/models/`:

```
backend/models/
  cnn_best.pth
  efficientnet_best.pth
  vit_best.pth
  unet_best.pth
```

You can also run `python notebooks/place_outputs.py` — it checks which files are present and copies weights automatically.

### 3. Start the backend

```bash
cd backend
pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```

Check that all models loaded: `http://localhost:8000/api/models/status`

```json
{"cnn": true, "efficientnet": true, "vit": true, "unet_segmentation": true}
```

### 4. Start the frontend

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

### 5. Docker (optional)

```bash
docker-compose up
```

## API

| Method | Endpoint | Description |
|---|---|---|
| GET | `/health` | Server liveness check |
| GET | `/api/models/status` | Which model weights are loaded |
| GET | `/api/metrics/classification` | Accuracy, F1, ROC-AUC per model |
| GET | `/api/metrics/segmentation` | U-Net Dice and IoU scores |
| POST | `/api/classify?model_name=...` | Single model classification + explainability overlay |
| POST | `/api/classify/compare` | All three models + averaged ensemble |
| POST | `/api/segment` | U-Net tumor mask and overlay |
| POST | `/api/analyze?classifier=...` | Classify, then segment if a tumor is found |

Interactive docs available at `http://localhost:8000/docs`.
